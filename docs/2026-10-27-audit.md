# iVidiBlocks (then iTetris) review, 2026-10-27

## Scope

Reviewed the engine, board and rotation models, scoring, input, SpriteKit rendering,
SwiftUI screens, settings, localization, local records, audio/haptics, tests and
Xcode configuration. No external dependencies or network-backed game services.

## Changes

- Connect held horizontal buttons to DAS/ARR. Release input when controls disappear.
- Wrap the control bar on narrow screens, use adaptive piece galleries, and enlarge
  pause/language touch targets to 44 points.
- Provide accessibility activation for controls, including a one-row soft drop.
- Prevent soft drop from slowing the natural gravity at high levels.
- Ignore invalid frame durations, paused input and zero-distance movement.
- Separate real run time from clamped physics steps, cap Ultra at 180 seconds,
  and round its displayed countdown up so zero only appears at expiry.
- Serialize record flushing with background writes so an older write cannot
  overwrite the latest flushed state.
- Preserve the music pause across preparation/configuration changes, restore
  menu music after leaving a paused game, and load the SFX preference on launch.
- Restart the haptics engine before a custom pattern and use fallback feedback
  when playback actually fails.
- Suppress line-clear animation with Reduce Motion enabled.
- Initialize/reset countdown state immediately.
- Keep board storage dimensions intact for repeated/out-of-range clear indices.
- Remove unused duplicate clear classification and its isolated test. Move the
  seeded random generator into the test target; it is not production functionality.
- Make per-run engine configuration immutable and prevent repeated test starts
  from silently replacing an active piece.

## Validation

- 120 XCTest tests passed on iPhone 17 Pro, iOS 26.5 Simulator.
- Release build for generic iOS passed with signing disabled.
- Xcode static analysis passed.
- Translation completeness/orphan checks for English and Portuguese passed as
  part of the test suite.
- Source/reference inspection found no further unreferenced production helpers;
  SpriteKit callbacks and test entry points are intentional.
- Xcode reports an informational App Intents metadata warning because this app
  does not use App Intents. Test tooling also logs a host OS build parsing message;
  neither prevented successful validation.

## Remaining validation and optional improvements

The computer-use tool could not resolve Simulator by name or application path, so
interactive visual verification was not completed. Layout changes compiled but
still need a visual pass on a small iPhone and an iPad, including larger text,
VoiceOver, light/dark themes and both control layouts. VoiceOver button activation
is provided; a fully nonvisual representation of the board is not implemented.

Real-device audio interruptions, haptic feel, prolonged play and frame pacing
remain manual checks. Release signing, archive/export and App Store submission
were not performed. Automated checks cannot establish bug-free operation.

A useful next feature would be saving an unfinished run across app termination.
The current app pauses when backgrounded but does not persist an active game.
Game Center/cloud synchronization would be separate product work; neither was
added during this maintenance review.
